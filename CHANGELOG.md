# Changes

## 0.3.0 (November 2026)

- Rebuilt the 2024 prototype as a FastAPI backend, a React/TypeScript UI and a small C# counter library.
- Removed keystroke and window-title logging. The app now only uses numbers the user enters.
- Added an optional OpenAI-compatible model with two versioned prompts, JSON output checks and a neutral fallback. The default is an offline mock.
- Added separate opt-ins for local storage and for sending text to a model, plus session deletion.
- Added tests, a Dockerfile and GitHub Actions.

## 2024

- MayDay HCI project: interviews, personas, wireframes, enactment session and the first C#/Python/JavaScript experiments. All kept in `legacy/`.
