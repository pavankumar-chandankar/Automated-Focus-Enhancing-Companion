# v0.13.1 — local tab-switch speech reminders

Tell Oplyra a concrete focus goal, e.g. "I am focusing on reliability engineering." With no active observation this offers a consent panel. Choose **Remind me on tab switches**. macOS screen recording authorization is required to obtain window titles. Close chat on the intended tab and stay there until analytics or the chat diagnostics reports the reference established. There is no manual tab/window chooser.

The independent native worker reads the current supported foreground window identity (bundle, window ID, title) roughly every two seconds using ScreenCaptureKit window metadata, no screenshot or OCR. Raw identity is immediately discarded after hashing. After a different identity persists for at least four seconds, offer one reminder per excursion, with a 30-second global cooldown. Return to the reference re-arms. Gaps/unsupported apps, private-title exclusions, open chat and dragging suspend continuity; they do not prove distraction. Same-title tabs cannot be distinguished and changing page titles can cause false positives. Timing depends on OS enumeration latency. No API requests, no title persistence, no automatic session actions. Strict mode is distinct from semantic Groq mode; it intentionally reminds even for a relevant tab change. The analytics sample counts remain uncertain (not semantic labels). The reference and counts are process/session-local. Stop, pause, finish or hide revoke consent.

A macOS AppKit NSPanel displays a short speech bubble to the left of the buddy, or right/above when near display edges. It cannot become key/main, ignores mouse, stays out of normal window cycling and closes after eight seconds. Opening chat, dragging or revocation dismisses it. Both semantic and local switch cues use this surface. Existing compact character animation is triggered by the event; if native display fails an inline cue is used. No new dependencies, no new webview, no resize of the character or chat. Windows retains existing unsupported screen stub.

Acceptance: open a non-sensitive document in Chrome, say the concrete goal, choose local reminders, fold and stay on document for at least 10 seconds. Switch to another clearly differently titled tab and stay 8–15 seconds. Verify speech bubble appears without focus steal or opening chat, disappears, and no new Groq requests occur. Return and after cooldown switch again. Test quick switches, open chat, dragging, stop, permission denial, display edges and tray hide. Build/test checks do not establish native UI or real browser title detection; verify on M1.

The compact badge says Finding focus tab… until the local reference is established, then Tab reminders on. Returning to the reference also dismisses the native cue. No provider key is needed for local reminders.

## v0.13.2 diagnostic correction
Explicit UI fold state gates tab monitoring rather than inferred window geometry. Native metadata first, SCK title fallback. On first valid reference, display a confirmation speech bubble. The menu-bar Test reminder bubble independently tests native delivery with no monitoring or API calls. Terminal logs contain fixed status/reason codes only, not titles or screen text. Click the intended tab once after folding to ensure it is foreground. If it cannot be identified, the monitoring diagnostics expose why. Neither CI nor synthetic tests verify the actual Mac's window metadata or native panel.

## v0.13.3 Chrome direct tab identity
Local reminder mode now targets normal Google Chrome windows only, replacing window-title estimation. Explicit consent requests a read-only AppleScript query via the system osascript tool; macOS Automation approval may be required (no Screen Recording permission for this mode). The fixed script reads only window mode, active tab ID and frontmost state, never URL, title, page or DOM. Private windows and other apps are observation gaps. Identity is hashed in memory including Chrome process ID, never persisted or sent to Groq. There is a bounded subprocess deadline, sanitized errors and no shell execution. Same-tab navigation is not a switch. Native fold/consent lifecycle logs contain no browser IDs. Pause, finish, quiet and hide explicitly revoke consent. Native AppleScript permission and AppKit rendering still need a real Mac test. The separate semantic OCR mode is unchanged. No new dependencies or paid service.
