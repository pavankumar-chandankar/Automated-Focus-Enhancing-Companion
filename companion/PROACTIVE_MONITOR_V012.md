# v0.12 — proactive goal-relative monitoring

## Workflow
Tell Oplyra "I am reading this document, keep me on track if I get distracted", or say "Watch my screen". Confirm/edit the actual focus goal and choose Monitor & remind me (Groq). This grants session-only automatic transmission of a short window title and OCR excerpt plus the declared goal to Groq, after sustained changes. Local observation only never sends screen-derived content automatically. No model can start monitoring or authorize transmission. OS recording permission is separate. Stop before viewing sensitive content; app/title exclusions are not comprehensive redaction.

## Monitoring
Native worker attempts capture every ~15s, including when chat is expanded, if the companion remains visible and the focus session running, excluding drag and own/unsupported apps. Capture uses selected foreground window, not full desktop. Accurate Vision OCR, language correction, higher bounded resolution and window title improve evidence; recognition still imperfect. Local key hashes title or content when title unavailable. Consecutive samples of the same key over 30s can request a semantic classification, cached by key (up to 64 per opt-in). The label is RELATED, POSSIBLY_UNRELATED or UNKNOWN; only a subsequent matching sample after 45s dwell can offer a passive reminder. At least 3 minutes between reminders, at most 4 per opt-in; no automatic pause or focus steal. Related videos/readings may be appropriate. No continuous cloud stream, no screenshots sent, no raw OCR persisted. Budget is existing 20 attempts per UTC day, background checks only while >8 remaining, at least 60 seconds between background checks. Requests already sent cannot be recalled. Failed/unknown classifications abstain. No exact attention measurement; title-based cache can miss changes within one page. Pause/finish/hide/stop revoke. Voice remains postponed.

## Analytics
Separate normal window opened via companion arrow button or menu-bar Open analytics. Native resizable/maximizable window, not an enlarged floating character. Displays current session duration and observed sample counts, related/possible/unknown counts, detected changes, attempts, offered check-ins and observed returns. No fabricated productivity score. Counters are process-local for the current monitoring run, not lifetime analytics; starting a new monitoring run resets them. Persistent quota contains only day/count/time. No data capture from analytics itself.

## Acceptance
Read reliability textbook, give actual goal, choose monitoring, fold bubble and read 45–75s. Switch to unrelated music/video tab and stay at least 45–90s (allow shared one-minute cloud cooldown); look for passive check-in, no automatic state change. Return to textbook; compare observed return count. Test a related educational video, brief switches and unsupported apps; no unwarranted interruption. Test stop, pause, hide, quota exhausted and analytics close/reopen/maximize. Test OCR with non-sensitive sample text. Validate CPU/RAM and model classifications on Mac; CI cannot establish actual runtime capture or user experience. No additional expenditure on Groq Free plan.

For a deictic goal such as “read this document,” start on the intended document. The first readable titled work window is treated as the user-selected reference and its title can be shared in the reasoning goal; if wrong, stop and begin again. Ordinary non-screen chat retains action proposals. Conservative title/content exclusions are incomplete. OCR evidence is data rather than system instructions.

The native background inference slot is separate from ordinary chat, but both share Groq rate-limit cooldown. Hiding the companion also closes an open analytics window to avoid a residual window. Title reference stays in RAM and is used in authorized background classification, not appended to unrelated chat prompts.
